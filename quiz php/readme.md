# 🎯 Quiz de Conhecimentos Gerais

Um quiz interativo desenvolvido em **PHP**, no qual o usuário responde a perguntas de múltipla escolha e recebe sua pontuação ao finalizar.

O projeto foi criado com o objetivo de praticar lógica de programação, manipulação de formulários e desenvolvimento web com PHP.

---

## 📸 Sobre o projeto

O Quiz de Conhecimentos Gerais permite que o usuário teste seus conhecimentos por meio de perguntas com alternativas.

### ✨ Funcionalidades

- ✅ Perguntas de múltipla escolha.
- ✅ Correção automática das respostas.
- ✅ Cálculo da pontuação final.
- ✅ Mensagens personalizadas de acordo com o desempenho.
- ✅ Opção para reiniciar o quiz.
- ✅ Interface responsiva.
- ✅ Layout com tema escuro.

---

## 🛠️ Tecnologias utilizadas

- **PHP** — Lógica do sistema e processamento das respostas.
- **HTML5** — Estrutura da página.
- **CSS3** — Estilização e responsividade.
